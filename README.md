# Alex Game Lab и akaalexey

- AGL: https://alexgamelab.ru/
- Личный сайт Алексея: https://alexgamelab.ru/akaalexey/

AGL написан на Vue 3 и TypeScript (`client/`). Главная, проекты, новости,
о команде, профиль и рабочее пространство — отдельные страницы с ленивой
загрузкой. Данные, права и публикации обслуживает `Alex-Game-Lab/backend` на VPS.
Личный сайт (`sites/akaalexey`) и подробная страница «Рублемёта» остаются
статическими. `akaalexey.ru` ещё не подключён к этой публикации.

## Сборка

```sh
cd client
npm ci
npm test
npm run build
cd ..
python3 tools/build_pages.py --sync-root
```

Vite записывает готовый клиент в `sites/agl/vue-dist`. Python собирает `_site`,
добавляет локальные изображения, фиксированные маршруты, legacy-страницы,
портфолио, sitemap и CNAME, проверяет ссылки. `--sync-root` обновляет экспорт
для совместимости с публикацией из ветки. `.github/workflows/pages.yml`
публикует только `_site` при изменении main; домен и способ публикации сохранены.
