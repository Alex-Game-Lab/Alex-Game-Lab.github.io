# Ключевые заметки, участники и сохранения

В списке пользователей и в поиске участников проектов рядом с регистрационным
логином показывается ключевая заметка длиной до 20 символов. Её также видно в
закрытом журнале действий. Заметка общая для сотрудников, которые имеют доступ
к соответствующему списку. В публичные страницы и профиль самого игрока она
не попадает. Длинные конфиденциальные заметки продолжают работать отдельно.

Ключевая заметка меняется в карточке аккаунта. Для этого нужно отдельное право
«Изменять ключевые заметки аккаунтов» и просмотр карточек. Владелец имеет доступ
по умолчанию. Поиск пользователей работает по логину, ключевой заметке, имени
профиля или ID; в подборе участников — по логину и ключевой заметке.

В редакторе роли есть группа «Допуск к участию в проектах»: можно добавлять
разработчиком и можно добавлять тестировщиком. Эти флажки не дают права назначать
других. Сначала укажи должность в проекте, затем найди пользователя и выбери его
из списка. Обычная роль «Игрок» не допускает назначения. Сервер повторно проверяет
допуск при сохранении, поэтому прямой запрос тоже не обходит правило.

В карточке аккаунта вкладка «Игра» открывает реальные сохранения Рублемёта.
Просмотр требует права на игровые показатели, правка — отдельного права на
коррекцию игрока. Новая Android-сборка 126 связывает AGL ID и текущий локальный
прогресс. Без переданного из игры сохранения сайт прямо сообщает об этом.
Для изменения доступны баланс, общий заработок, число взмахов и остальные данные
прогресса. Причина фиксируется в журнале; устаревшая версия не перезаписывается.

В профиле баланс показывается только когда он получен из игрового сохранения.
Проверочные данные старой таблицы показателей не выдаются за реальный прогресс.

Проверки: TypeScript/Vite, четыре теста помощников, проверка страниц и ссылок;
ограниченная браузерная проверка карточки сохранения и выбора участника при ширине
390 px, без горизонтального переполнения и ошибок JavaScript. Браузер использовал
изолированные примеры аккаунтов; реальные права и записи проверены серверными
тестами на PostgreSQL с подписанными тестовыми идентификаторами.
