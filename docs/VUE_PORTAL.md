# Vue-портал AGL

## Страницы и данные

`views/` содержит отдельные страницы главной, каталога, проекта, новостей,
статьи, о команде, профиля и кабинета. Каждый раздел открывается отдельной страницей через обычную ссылку. Vue Router
выбирает представление текущего URL; переходы не прокручивают общий лендинг.
`components/` — карточки, диалоги, пагинация, уведомления и безопасный Markdown.
`lib/` — типы контракта, API, ошибки, черновики и локальный реестр иллюстраций.

Добавление проектов не требует верстать новую страницу: каталог и детали читают
API. Публичная команда пока представляет только Алексея. Новые роли и назначения
создаются через кабинет; количество участников не захардкожено в панели.
Публичные списки новостей и пользователей используют пагинацию и поиск.

## Кабинет

Статьи: список своих/разрешённых записей, поиск и статус; Markdown-редактор,
предпросмотр, выбор локальных обложек и иллюстраций, публикация, архив и удаление.
Несохранённые правки хранятся в текущей вкладке до 24 часов с привязкой к аккаунту.
При конфликте `expected_revision` сервер не перезаписывает чужую версию.

Роли: название, идентификатор, описание, цвет, поиск и группы разрешений,
копирование и удаление неназначенных ролей. API определяет доступность изменений.
Owner нельзя создать или назначить через редактор ролей. Admin не получает
игровые начисления и не делегирует старшие права; персональные allow/deny — Owner.

Отдельные разделы: проекты и назначения разработчиков/тестировщиков,
аккаунты и баны, закрытые отчёты, метрики и идемпотентные игровые корректировки,
неизменяемый журнал. UI помогает выбрать действие, сервер проверяет полномочия.

## Вход

Пароли находятся только на AGL ID. Токены живут в памяти; PKCE state и черновики
в sessionStorage. CSP ограничивает подключения API и IDP. Действия в рабочем пространстве используют обычную сессию и серверные права.
Повторный вход нужен только для защиты аккаунта: смены пароля и привязки телефона.
Мобильный аутентификатор отключён.
SMS остаётся выключенным до настройки и согласования провайдера.

## Размещение и проверка

Готовый Vue-клиент по-прежнему публикуется на GitHub Pages. Фиксированные страницы
имеют свои HTML, title, description и canonical; приватные страницы исключены
из индексации. Для новых dynamic URL применяется ограниченный возврат через 404.
Старые личные/игровые страницы сохранены. Полные e2e не запускались: проверяются
сборка, типы, ссылки, небольшие API-контракты и визуальное состояние страниц.
