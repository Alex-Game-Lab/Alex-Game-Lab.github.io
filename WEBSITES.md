# Сайты AGL и akaalexey — GitHub Pages

Публикация: AGL в корне https://alexgamelab.ru/, личный сайт в
https://alexgamelab.ru/akaalexey/. Отдельный домен akaalexey.ru не перенастраивался.

Сайты содержат восемь страниц, шесть новых иллюстраций, локальные шрифты,
адаптивную навигацию, анимацию с поддержкой reduced motion, страницы
конфиденциальности и 404. На AGL открыт только профиль Алексея. Личный сайт
поддерживает светлую и тёмную темы.

## Исходники

- `sites/agl/` — AGL, его настройки, сборка и готовый `dist/`.
- `sites/akaalexey/` — личный сайт, его настройки, сборка и готовый `dist/`.
- `tools/build_pages.py` — сборка общего артефакта `_site/`.
- `tools/check_pages.py` — проверка собранных страниц, локальных ресурсов,
  якорей, абсолютных переходов между сайтами, CSS-шрифтов и sitemap.

Проверка: `python3 tools/build_pages.py --sync-root`. Проверены 104 ссылки и
ресурса AGL, 92 личного сайта и 165 внутренних ссылок и ресурсов общего
артефакта, включая переходы между сайтами. Проверяются структура HTML,
метаданные и JSON-LD; страницы 404 закрыты от индексации. Sitemap включает
публичные страницы обоих сайтов.

Экспорт в корне обновлён для существующей публикации из ветки. Workflow
GitHub Actions использует только собранный `_site/`. Файл CNAME сохраняет
действующий домен alexgamelab.ru.

Предыдущие закрытые версии в ChatGPT остаются отдельными снимками:
