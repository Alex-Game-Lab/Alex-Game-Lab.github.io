Данные и конфиденциальность

Какие данные используются на сайте и в AGL ID.

Аккаунт

AGL ID хранит ник, идентификатор аккаунта и почту, если она указана. В профиле сохраняются выбранное отображаемое имя, описание, язык и аватар. Имя и почта не обязательны для регистрации.

Пароль обрабатывает Keycloak. В базе хранятся данные проверки пароля, а не открытый пароль. Вход использует сессии и токены.

Действия в сервисе

К аккаунту могут быть привязаны роли, игровые сохранения, показатели игры, отзывы, публикации и отчёты о тестировании. Эти данные нужны для соответствующих функций. Сотрудники с отдельным правом могут оставлять закрытые заметки об аккаунте; их видят автор заметки, Admin и Owner. Удаление в корзину закрывает доступ, но сохраняет записи для восстановления и не стирает учётную запись AGL ID. Публичные материалы показывают имя автора; закрытые данные доступны согласно правам аккаунта.

Технические данные

Хостинг, сервер и система входа обрабатывают технические сведения запросов и сессий. Журнал приложения содержит маршрут, статус, время ответа и идентификатор запроса; код этого журнала не записывает пароль, токен, содержимое запроса или строку поиска.

В код сайта не добавлены рекламные и аналитические счётчики. Выбранная тема, опубликованное содержимое и локальные копии черновиков могут сохраняться в браузере. Их можно удалить вместе с данными сайта.

Размещение и внешние сервисы

Публичные страницы размещены на GitHub Pages. API и AGL ID работают на отдельном сервере. Переходы к Telegram и GitHub открывают внешние сервисы с собственными правилами обработки данных.

Текущее состояние

Почту при регистрации можно оставить пустой. Письма подтверждения и восстановления сейчас не отправляются. Вход по SMS не подключён. Telegram-бот для обращений к администрации также пока не подключён; действующая ссылка будет добавлена после запуска.
